Inheritance downcasting is dangerous

Converting a base-class pointer to a derived-class pointer is downcasting. We should be careful when we do that in order to avoid UBs.

Consider the following code.



The Take-Away:


Never downcast a base pointer to a derived type unless you are sure about the object that it points to. Static cast will compile but will do it as the name suggests, statically. Prefer dynamic_cast and perform a runtime check for the returned ptr.

If we would have a Derived --> Base, this is upcasting the pointer, it is safe and implicit.
But for Base --> Derived, this is downcasting, always dangerous without dynamic_cast.
